## shiki 代码高亮配色机制（调研结论）

版本：@vuepress/plugin-shiki 2.0.0-rc.108，shiki 3.7.0

消费规则在 `node_modules/@vuepress/plugin-shiki/lib/client/styles/shiki.css`：
```
.shiki span { color: var(--shiki-light, inherit) }
[data-theme=dark] .shiki span { color: var(--shiki-dark, inherit) }
div[data-highlighter=shiki] { background-color: var(--code-c-bg, var(--shiki-light-bg)) }
```
- `--shiki-light` / `--shiki-dark` 由 shiki 以**行内 style** 逐 token 写入（仅双主题 `themes` 模式才有），故**无法在 CSS 中覆盖**（行内优先级最高，且覆盖成单值会丢失语法高亮）
- 插件默认 `theme = 'nord'`（单主题）；单主题模式直接输出 `color:#xxx`，不产生 `--shiki-light`
- 正确改法三选一：
  1. 换主题：`theme.ts` → `plugins: { shiki: { theme: 'github-light' } }`，或用 `themes: { light, dark }`（二者互斥，二选一）
  2. 精细自定义：`theme: 'css-variables'`，在 index.scss 定义 `--shiki-color-text`、`--shiki-color-background`、`--shiki-token-<scope>`（scope 含 comment/keyword/string/function/constant/parameter/punctuation/link 等）
  3. 只改底色：覆盖 `--code-c-bg`，或用 Sass 变量 `$code-bg-color`；另有 `--code-c-text`（默认 #9e9e9e，行号）、`--code-c-highlight-bg`（高亮行背景）可直接覆盖
- theme-hope 的 theme options 支持 `plugins.shiki`（类型 `ThemeShikiPluginHelper`），无需手动 import 插件
- 改 config/theme 需重启 dev server；改 index.scss 可热更新

### shiki "白底白字"问题（已定位根因，实测重现）

现象：部分 token 行内样式为 `--shiki-light: white`，浅色模式下看不清。

根因链（已验证）：
1. theme-hope 默认给 shiki 配双主题：`themes: { light: 'one-light', dark: 'one-dark-pro' }`（theme.ts 未配置时的兜底，源码 `sa({..."theme" in t?{}:{themes:{light:"one-light",dark:"one-dark-pro"}},...t})`）
2. plugin-shiki 双主题模式强制 `defaultColor: false`，输出 `--shiki-light`/`--shiki-dark` 两个变量，CSS 用 `color: var(--shiki-light, inherit)` 消费
3. **one-light 主题本身把若干 token 定义为字面量 `white`**（HTML 中 PascalCase 组件标签名如 `<MyComponent>`、CSS 字符串内的路径片段、十六进制色值 `#00c6ff` 等），浅色背景 #FAFAFA 上白底白字 → 不可见
4. 用项目内 shiki 3.7.0 实测重现，`<MyComponent>` 输出 `style="--shiki-light:white;--shiki-dark:#E06C75"`

修复方案：
- A（推荐）：theme.ts → `plugins: { shiki: { themes: { light: 'github-light', dark: 'one-dark-pro' } } }`，github-light 已实测无 white token
- B（保留 one-light）：index.scss 加 `html:not([data-theme='dark']) .shiki span[style*='--shiki-light:white'] { color: #e45649; }`（利用属性选择器匹配行内样式，specificity 高于 `.shiki span` 规则，无需 !important）
